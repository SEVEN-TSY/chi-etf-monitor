# 顶部指标调整

## 已确认需求

- 顶部指标随选择的历史日期变化；未选择时沿用当前可视范围最后一个数据日。
- 观察池为中央汇金的8只重仓ETF，只观察标的自身变化，不监控或推算汇金实际持仓。
- 展示当日总份额、较前一交易日的份额增减、单日增减率及增减率较前一日的百分点变化。
- 指南针0AMV主数值展示当前查看数据日的当日涨跌幅，卡片内附最近触发记录；默认浏览时另以小字标注独立最新已收盘数据。
- 增加申赎异常程度，帮助识别异动和份额变化放大。
- 顶部保留四张卡：总份额、单日增减率、0AMV当日涨跌幅、申赎异动。
- 份额变化广度与异常程度在同一张卡中，例如`6/8增加`、`2/8减少`，持平及待齐/复核的数量分别标注。
- 不增加净申赎金额、持续天数或汇金持仓等指标。
- 数据优先读取SQLite；0AMV缺失时调用现有采集能力并保存后展示。

## 0AMV数据接入

历史来源为`E:/0me/codex/股票/指南针0AMV历史数据.xlsx`的`0AMV日线`工作表。
只读取日期、0AMV收盘值和当日涨跌幅，忽略工作表汇总及触发规则。
Excel百分比以小数保存，入库时乘100；直连脚本已经返回百分数，直接入库。
例如数据库中的`0.36`表示`+0.36%`。

目标数据库为`../data/etf.sqlite3`，独立表`amv_observations`保存日期、收盘值、涨跌幅、来源、原始数据路径、采集时间。
历史导入仅追加缺失日期，不改写原Excel，不覆盖已有数据。
采集复用股票项目的`fetch_0amv_direct.py`；原始日K响应另存到`../data/raw/0amv/`。
单日命中数据库时不联网；缺失时读取日K，按返回的交易日期入库，不生成休市日记录。
只补采已收盘日期；未返回指定日期时保留缺失，不以相邻日代替。

在frontend目录运行：

```powershell
python scripts/amv_sync.py --import-xlsx 'E:/0me/codex/股票/指南针0AMV历史数据.xlsx'
python scripts/amv_sync.py --date 2026-10-22
python scripts/amv_sync.py --start 2026-10-19 --end 2026-10-22
```

路径可通过`--database`与`--fetch-script`覆盖。此命令可供已有定时采集任务调用。
页面针对当前卡片日期按需请求`POST /api/amv/sync`；默认浏览时还会独立检查最新已收盘日期，补采资格不依赖同日ETF记录。`GET /api/dashboard`继续只读。
同日并发补采合并执行，其他日期等待；失败或未发布时5分钟内不重复联网，隐藏页面暂停补采。
补采完成后刷新数据，保留当前日期、视口及详情状态；独立定时任务更新0AMV也会改变ETag，页面自动读取。
0AMV按同一交易日关联，缺失时显示补采状态，不借用相邻日数值。
采集命令通过Python标准库执行，使用系统`python`；可用`AMV_PYTHON`和`AMV_FETCH_SCRIPT`环境变量指定解释器与原采集脚本。

## 0AMV日期与最近触发记录

实现规格：[Issue#1](https://github.com/SEVEN-TSY/chi-etf-monitor/issues/1)。

手动选择数据日时，主数值和触发截止日始终使用该日；选择移出视口仍保留该日，不展示最新数据小字。刷新页面后取消选中日期，恢复默认浏览；其余时间范围等偏好继续恢复。后台数据刷新仍保留本次页面会话中的选择。
双击图表取消选中日期，并将时间窗口移到最新数据日；自定义窗口保留跨度，预设范围保留原预设。取消后指标使用最新数据日，恢复独立最新0AMV数据小字。
默认浏览时，主数值使用图表可视范围末日，小字标注独立0AMV历史中最新已收盘数据的日期及涨跌幅，即使其日期与主数值日期相同也保留标注。
最近触发记录在默认浏览时使用截至当前日期的全部可用已收盘0AMV历史，不受ETF末日或视口限制。

触发条件使用数据库原有百分数精度：

- 单日当日涨跌幅严格小于−2.3%；恰好−2.3%不触发。
- 单日涨幅严格大于4%；恰好4%不生成单日上涨事件，无需前一日数据。
- 相邻两交易日当日涨跌幅的算术和严格大于4%；恰好4%不触发，不计算复合收益率。比较保留存储数值的十进制精度，−4.05%与+8.05%也按恰好4%处理。
- 两日事件日期为第二个交易日；同日先取单日下跌，其次单日上涨，再取两日上涨。跨日期先取最新事件，不按类型覆盖时间顺序。

卡片只显示一条最近触发记录，以醒目的红色“多”或绿色“空”徽标引导，后接日期与触发原因，不再显示“最近触发”标题或强制换行。例如“空：2026-10-15单日跌破−2.3% · −2.45%”“多：2026-10-15连续两日涨超4%”“多：2026-10-15单日涨超4%”。主数值下移除“当日涨跌幅”说明，缺失时仍展示补采状态。
无事件时显示“截至该日的可用历史中暂无触发”，与主数值缺失或补采状态分别显示。
两日计算可以跨周末及已经成功查询且没有交易记录的休市日；已知交易日缺0AMV时不拼接，尚未确认的工作日空档也不推测连续性。仅有单日数据时只判断单日条件。
收盘界限为北京时间15点，周末默认目标回退到前一工作日；节假日或未发布日期保持缺失，不制造记录，展示明确状态并限频重试。
0AMV数据独立更新后继续通过ETag及现有轮询刷新，保留选中日期、视口和详情状态，不改变现有定时采集任务。

## 异动与广度口径

异动强度=`Σ|当日份额−前一交易日份额|÷前一交易日总份额×100%`。
合计净增减继续显示于总份额卡；广度逐只统计份额增加、减少和持平，分母始终为观察池ETF总数。
缺失、待复核或前一交易日不可比较时单独显示，不当成持平或零变化。
历史百分位只使用当前所选日期之前60个交易日，同值取中间排名。当前强度大于零且达到95分位显示“异常放量”，80至95分位显示“异动偏高”，其他显示“常态”。
历史不足60日或窗口内存在不可比较数据时不计算百分位，仍展示可用的当日强度与广度。

异常强度用于观察份额变化，无法单独确认趋势反转；不使用成交量或资金金额描述其数值。
